## How to Run

1. Install Python 3 on your computer.
2. Open the project in Visual Studio Code.
3. Create a Python file (example: `task1.py`).
4. Write or paste the required program.
5. Open the terminal.
6. Run the following command:

```bash
python task1.py
```

7. Enter the required input when prompted.
